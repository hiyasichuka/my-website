## 主要プロジェクト実績

### 1️⃣ **ペタバイト超のデータ基盤移行プロジェクト**

**DMM.com | 2024 年~**

DMM の全社横断データ基盤を Google Cloud へ移行するリーディングプロジェクト。

**背景**

- 2022 年にマーケティング施策のデータ活用強化方針が打ち出される
- オンプレミスの既存基盤の限界が顕在化
- 子会社 EXNOA の Google Cloud + Looker 活用実績を参考に移行決定

**責務**

- データマネージメントグループの統括マネージャーとして全体指揮
- 複数データソースから Google Cloud への堅牢なパイプライン設計
- セキュアな通信経路構築（VPN・専用線の活用）

**主要な技術課題と解決策**

- **課題**: オンプレミス ↔ クラウド間のセキュアなデータ転送
  → VPN・専用線設計 + ネットワークセキュリティ強化
- **課題**: 膨大で複雑なデータソースの効率的な統合
  → YAML 設定ベースのスケーラブルなパイプライン自動化フレームワーク開発
  → Python + シェルスクリプトで実装
- **課題**: 人為ミスの削減と運用の安定化
  → Terraform によるインフラストラクチャコード化（IaC）
  → 結果: ヒューマンエラー削減 + 高い可用性実現

**技術スタック**

- Google Cloud (BigQuery, Dataflow, Composer, Cloud Functions)
- Terraform (IaC)
- Python, Shell Script
- VPN / 専用線設計

**成果**

- ✅ 毎日数億件のデータを安定的に転送
- ✅ マーケティング施策実行のリードタイム短縮
- ✅ リアルタイムマーケティング基盤の構築開始

### 2️⃣ **エンジニアリングマネジメント体制の構築**

**DMM.com | 2024 年 2 月~**

新規入社から 4 ヶ月でデータマネージメントグループの Manager に昇進。

**職務内容**

- **チーム統括**: エンジニアチームの採用・育成・評価
- **戦略立案**: データ基盤の中長期ロードマップ策定
- **ステークホルダー管理**: 経営層・各事業部との折衝
- **技術的意思決定**: Google Cloud 導入アーキテクチャの決定

**Google Cloud との連携**

- 2 週間ごとに Google Cloud エンジニアとの技術ディスカッション
- ベストプラクティスの吸収と導入

**リーダーシップの特徴**

- データドリブンな意思決定
- チームの主体性と技術スキル向上を促進
- DMM の「チャレンジ文化」を実践
